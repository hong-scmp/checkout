How to test key scenarios

Returning user

Enter abc@abc.com on the email screen to show the password login flow.

New user

Use any other valid email address to see the creating-account loading screen, then continue to payment.

Promo code

In the payment step, open “Got a promo code?” and apply SCMPDISCOUNT50 to test the discounted plan summary.

Invalid email

Enter an email without @ to check the validation warning state.

Social sign-in

Choose Google, Apple, or Facebook to preview the simplified provider sign-in screens and loading state.

Payment method changes

Choose a payment method, then click “Change” in the Payment row to return to the payment selection step.
